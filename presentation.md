# Futuristic NFT Project Demo

## 1. Kirish
- Loyiha nomi: **Futuristic NFT dApp**
- Maqsad: NFT-larni oson yaratish va ovoz berish tizimini joriy qilish.

## 2. Smart-kontrakt (Solidity)
- ERC721 standartiga asoslangan.
- OpenZeppelin kutubxonasidan foydalanilgan.
- Funksiyalar: `mintNFT`, `vote`, `getVotes`.

## 3. Frontend (React + Ethers.js)
- Zamonaviy **Glassmorphism** dizayn.
- To'liq **Dark Mode**.
- Responziv interfeys.

## 4. Web3 Integratsiyasi
- MetaMask hamyonini ulash.
- Real-vaqtda blokcheyn ma'lumotlarini o'qish.
- Tranzaksiyalarni tasdiqlash.

## 5. Xulosa
- Loyiha NFT ekotizimini yanada qulay va interaktiv qilishga qaratilgan.
